## Phase 4: Merge MCP Adapters vào Platform Configs

### 4A. Hiểu cấu trúc config của từng platform

| Platform | Config File | Format | Merge Target |
|----------|-------------|--------|--------------|
| Codex | `~/.codex/config.toml` | TOML | `[mcp_servers.*]` sections |
| Claude | `~/.claude/.claude.json` | JSON | `mcpServers` object |
| OpenCode | `~/.config/opencode/opencode.json` | JSON | `mcpServers` object |
| Grok | `~/.grok/mcp.json` | JSON | `mcpServers` object |
| Antigravity | `~/.gemini/config/mcp_config.json` | JSON | `mcpServers` object |
| Cursor | `~/.cursor/mcp.json` | JSON | `mcpServers` object |
| MiMoCode | `~/.config/mimocode/mimocode.jsonc` | JSONC | `mcpServers` object |

### 4B. Merge logic cho JSON platforms (Claude, OpenCode, Grok, Antigravity, Cursor, MiMoCode)

**Algorithm:**
1. Đọc file config hiện tại
2. Parse JSON/JSONC
3. Nếu chưa có `mcpServers` key → tạo object rỗng
4. Thêm 5 MCP servers vào `mcpServers` (không ghi đè nếu đã có cùng key)
5. Ghi lại file

**Code TypeScript mẫu (thêm vào `packages/cli/src/runtime/installer.ts`):**
```typescript
async function mergeMcpConfig(platform: string, configPath: string): Promise<void> {
  const servers = {
    "codebase-memory": {
      command: "/home/linhnx/.local/share/codebase-memory-mcp/codebase-memory-mcp",
      args: []
    },
    "context7": {
      command: "npx",
      args: ["-y", "@upstash/context7-mcp@latest"]
    },
    "playwright": {
      command: "npx",
      args: ["-y", "@playwright/mcp@latest", "--headless", "--isolated"]
    },
    "chrome-devtools": {
      command: "npx",
      args: ["-y", "chrome-devtools-mcp@latest"]
    },
    "pencil": {
      command: "npx",
      args: ["-y", "@pencil-ai/mcp@latest"]
    }
  };

  let config: Record<string, any> = {};
  try {
    const raw = await fs.readFile(configPath, 'utf8');
    // JSONC: strip comments before parse
    const cleaned = raw.replace(/\/\/.*$/gm, '').replace(/\/\*[\s\S]*?\*\//g, '');
    config = JSON.parse(cleaned);
  } catch {
    // File doesn't exist or invalid → start fresh
  }

  if (!config.mcpServers) config.mcpServers = {};

  for (const [key, value] of Object.entries(servers)) {
    if (!config.mcpServers[key]) {
      config.mcpServers[key] = value;
    }
  }

  await fs.writeFile(configPath, JSON.stringify(config, null, 2), 'utf8');
}
```

### 4C. Merge logic cho TOML platform (Codex)

**Algorithm:**
1. Đọc file config hiện tại
2. Kiểm tra mỗi `[mcp_servers.*]` section đã tồn tại chưa
3. Nếu chưa → append section mới vào cuối file
4. Ghi lại file

**Code TypeScript mẫu:**
```typescript
async function mergeMcpConfigToml(configPath: string): Promise<void> {
  const servers = [
    { key: 'codebase_memory', command: "'/home/linhnx/.local/share/codebase-memory-mcp/codebase-memory-mcp'", args: '[]' },
    { key: 'context7', command: '"npx"', args: '["-y", "@upstash/context7-mcp@latest"]' },
    { key: 'playwright', command: "'npx'", args: "['-y', '@playwright/mcp@latest', '--headless', '--isolated']" },
    { key: 'chrome-devtools', command: "'npx'", args: "['-y', 'chrome-devtools-mcp@latest']" },
    { key: 'pencil', command: "'npx'", args: "['-y', '@pencil-ai/mcp@latest']" },
  ];

  let content = '';
  try {
    content = await fs.readFile(configPath, 'utf8');
  } catch {
    // File doesn't exist → create new
  }

  for (const server of servers) {
    const section = `[mcp_servers.${server.key}]`;
    if (!content.includes(section)) {
      content += `\n# agent-rules\n${section}\ncommand = ${server.command}\nargs = ${server.args}\nstartup_timeout_sec = 120\n`;
    }
  }

  await fs.writeFile(configPath, content, 'utf8');
}
```

### 4D. Gọi merge trong install flow

Thêm vào `packages/cli/src/commands/install.ts` sau khi install runtime:

```typescript
// After runtime install, merge MCP configs
const mcpConfigPaths: Record<string, string> = {
  codex: path.join(home, '.codex', 'config.toml'),
  claude: path.join(home, '.claude', '.claude.json'),
  opencode: path.join(home, '.config', 'opencode', 'opencode.json'),
  grok: path.join(home, '.grok', 'mcp.json'),
  antigravity: path.join(home, '.gemini', 'config', 'mcp_config.json'),
  cursor: path.join(home, '.cursor', 'mcp.json'),
  mimocode: path.join(home, '.config', 'mimocode', 'mimocode.jsonc'),
};

for (const [platform, configPath] of Object.entries(mcpConfigPaths)) {
  if (platform === 'codex') {
    await mergeMcpConfigToml(configPath);
  } else {
    await mergeMcpConfig(platform, configPath);
  }
}
```

```bash

npm view @playwright/mcp versions
npm view @pencil-ai/mcp versions 2>/dev/null || echo "Not on npm"
```

### Nếu platform config file không tồn tại
- Tạo mới với content `{ "mcpServers": {} }` (JSON) hoặc rỗng (TOML)
- Merge sẽ thêm servers vào

- Fallback: manual copy từ `generated/runtime-build/cursor/`
- Tạo receipt file thủ công

- Check GitHub releases page
- Fallback: dùng npm version nếu có
