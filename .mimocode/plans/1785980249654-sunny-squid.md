## §5. Dev Mock Mode

### Current State
- No dev-mode toggle, no local data loader, no fixture server
- Test fixtures exist (`packages/engine/test/fixtures/`, `schemas/fixtures/`, `evals/fixtures/`)
- Runner always spawns real agent CLIs

### Design: `dev mock mode`
Every project should have a `dev mock mode` that:
1. Provides realistic local data (not empty states)
2. Can be toggled on/off via env var or config
3. Does NOT affect CI/CD or production
4. Allows QA to test all states (loading, empty, error, populated)

### Actions

**Step 1: Create mock data file**

`packages/control-plane/src/db/mock-data.ts`:
```typescript
export const mockPlans = [
  { id: 'plan-001', name: 'Demo Plan', status: 'active', createdAt: new Date().toISOString() },
  { id: 'plan-002', name: 'Completed Plan', status: 'completed', createdAt: new Date().toISOString() },
];

export const mockRuns = [
  { id: 'run-001', planId: 'plan-001', status: 'running', startedAt: new Date().toISOString() },
];

export const mockEvaluations = [
  { id: 'eval-001', planId: 'plan-001', result: 'pass', score: 95 },
];
```

**Step 2: Create dev mock middleware**

`packages/control-plane/src/middleware/dev-mock.ts`:
```typescript
import { mockPlans, mockRuns, mockEvaluations } from '../db/mock-data.js';

export function devMockMiddleware(req, res, next) {
  if (process.env.DEV_MOCK !== '1') return next();
  
  if (req.path === '/api/plans') return res.json(mockPlans);
  if (req.path === '/api/runs') return res.json(mockRuns);
  if (req.path === '/api/evaluations') return res.json(mockEvaluations);
  
  next();
}
```

**Step 3: Register middleware**

In `packages/control-plane/src/server/server/index.ts`, add before routes:
```typescript
import { devMockMiddleware } from '../middleware/dev-mock.js';
app.use(devMockMiddleware);
```

**Step 4: Create `.env.development`**
```

```

**Step 5: Add to `.gitignore`**
```

```
