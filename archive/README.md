# Archive

**Purpose:** Historical project data that is no longer active runtime context.  
**Routing:** NEVER auto-loaded. Read only for historical traceability.

## What archive is for

Archive preserves:
- Overlay data for projects that no longer receive active context updates
- Completed project specs that are retained for legal/traceability
- Content that has been superseded by newer patterns

## Why archive is NOT runtime context

Archive content:
- Contains stale or superseded facts
- May reference project-specific names/assumptions that no longer apply
- Has not been validated against current project state
- Would pollute active context if auto-loaded

## Archive vs Evidence

| | Archive | Evidence |
|---|---|---|
| Content | Historical project data | Audit/research material |
| Source | Project overlays, completed specs | Feedback, audits, examples |
| Promotion | Not promoted automatically | Can be promoted after review |

## Sync

Archive is static in agent-rules. Never synced to project repos.
