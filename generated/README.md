# Generated Project Context

**Purpose:** Machine-generated context packages for 5fedu projects.  
**Routing:** Never auto-loaded. Read only by the context router when the matching project is active.

## Properties

- **Never hand-edited.** All content is generated by automation scripts.
- **Source-identified.** Every generated file tracks its source files and version.
- **Staleness-detectable.** A manifest records the generation timestamp and source hash.
- **Context-router compatible.** The router checks staleness before loading.

## Staleness detection

Each generated context includes a manifest with:
- `generated_at`: ISO timestamp
- `source_commit`: Git hash of source files at generation time
- `source_patterns`: Glob patterns identifying source files
- `version`: Schema version of the context package

If the source commit differs from HEAD, the context is stale and must be regenerated.
