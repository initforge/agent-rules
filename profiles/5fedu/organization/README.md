# Organization-wide 5fedu Conventions

**Purpose:** Conventions that apply to every 5fedu project across all domains.  
**Routing:** Never auto-loaded. Read only when understanding org-level policy.

## What belongs here

- Policies that span all 5fedu projects
- Cross-project conventions (naming, structure, process)
- Technology baseline decisions

## What does NOT belong here

- Domain-specific patterns → `domains/`
- Project-specific facts → `projects/<name>/`
- Evidence/audit → `evidence/`
- Historical content → `archive/`
