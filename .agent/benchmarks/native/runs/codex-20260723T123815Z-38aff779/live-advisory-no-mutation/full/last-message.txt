## Kiến trúc hiện tại

Repo mô tả kiến trúc phân tầng một chiều:

`Client request → Gateway → OrderService → OrderRepository → Storage`

- **Gateway**: tiếp nhận request và kiểm tra dữ liệu ở tầng giao tiếp/transport.
- **OrderService**: xử lý và sở hữu các quy tắc nghiệp vụ đơn hàng.
- **OrderRepository**: đóng gói việc lưu trữ và truy xuất dữ liệu.

Cách phân chia này giúp nghiệp vụ không phụ thuộc trực tiếp vào giao thức nhận request hoặc chi tiết persistence.

Hiện repo mới chỉ có tài liệu kiến trúc, chưa có source triển khai, cấu hình hạ tầng, database schema, API contract hoặc test; vì vậy chưa thể xác nhận framework, cơ chế dependency injection hay loại cơ sở dữ liệu.
