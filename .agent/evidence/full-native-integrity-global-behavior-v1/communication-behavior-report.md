# Communication Behavior Report

## Principle
Natural communication is the single default behavior embedded directly in rules/00-intent-scope-safety.md.
- Speaks in user language (plain, natural, outcome-first).
- Technical detail is included automatically when needed for debugging, verification, architectural decisions, or when requested.
- Zero mode switches, zero synthetic profiles (no vibe-coder, no plain-vietnamese, no technical_explain).
- Safety, scope boundaries, and verification rigor remain 100% strict regardless of tone.
