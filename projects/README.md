# Projects

**Vai trò:** Project context templates.
**Ý đồ:** Tách project context khỏi harness global context.

| Path | Mục đích |
|---|---|
| `context-template/` | Pointer mỏng mẫu |

Context sống **không** nằm ở đây — chỉ trong `<repo>/context/<profile>/` sau cài.

Xem `profiles/` cho optional organization profile templates.
